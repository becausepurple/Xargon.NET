## Basis of this port

Xargon.NET was written by studying and translating the original source code that Allen Pilgrim published, at:

<https://github.com/dos-games/vanilla-xargon>

That repository includes the file `Kiloblaster_and_Xargon_Freeware_License.txt` (dated August 4, 2008). Please read the full original file there; it is the authoritative text. The part of it that sets out the terms reads:

> Finally, I included the source code for "Kiloblaster" and "Xargon." My intent is to allow people to use this in any way they choose, including to create a commercial product. The two limitations are: 1) They can't release a game that in any way resembles either of my games and, 2) They can't use it for anything pornographic, illegal or in any way immoral. Those are my only requirements.
>
> Allen Pilgrim

Because Xargon.NET is derived from that source code, those terms apply to it.

## Game data is not included

This repository contains only the port's code. None of Xargon's data files (graphics, levels, text, sound, music) are included, and none may be committed here. Users supply their own copy of the original data files; see the README.
